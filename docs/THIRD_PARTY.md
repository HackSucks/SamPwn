PyInstaller release are not included.

### Local modification

`vendor/samsung_tv_root/src/samsung_tv_root/archive_root.py` is patched so the
TV-side launcher is detached from the `sdb` transport:

* launch with `setsid /bin/sh -c ...` and close fd 3;
* redirect launcher output to `launcher.console.log`;
* poll for the launcher exit log instead of waiting on the sdb capture;
* use the client's timeout for capture commands when no explicit timeout is
  given.

This fixes a real `sdbd` serialization problem: an attached launcher holds the
single sdb shell for the whole root session and blocks later injections. The
patch does not change the exploit primitive.

## common31 payloads

* Path: `vendor/payloads/common31/`
* Files: `SamsungTvArchiveRoot.dll`, `SamsungTvRootAgent.dll`
* Origin: compiled from upstream `samsung-tv-root` 0.0.12
* License: Unlicense

The upstream release also contains runtime-config/dev files and .NET 6
`common` payloads. SamPwn stages only the two assemblies that
`archive_root.PAYLOAD_FILES["common31"]` actually needs; the runtime configs
are generated by the exploit at run time.

## Adwaita Mono font

* File: `app/sampwn-mono.ttf`
* Family: Adwaita Mono, Regular
* Copyright 2015-2026, Renzhi Li (aka. Belleve Invis, belleve@typeof.net)
* License: **SIL Open Font License 1.1**
* Full text: [`app/FONT-LICENSE.txt`](../app/FONT-LICENSE.txt)
* Source font: `/usr/share/fonts/Adwaita/AdwaitaMono-Regular.ttf` on the build
  host

Subset details:

* printable ASCII (U+0020–U+007E), 95 cmap entries, 100 glyphs;
* layout features and hinting removed;
* 11,008 bytes;
* `ascent 965`, `descent -215`, `unitsPerEm 1000`.

The font is bundled because the tested TV has no monospace font; its
`monospace` alias resolves to a proportional Samsung font, which destroys the
figlet ASCII grid.

## Show audio

`app/pwned.mp3` is the 4:57 show soundtrack (MP3, 44.1 kHz stereo, ~80 kbps).
It is part of the show assets. It is **not** covered by the MIT license text
unless the repository owner says so; verify that you have the right to
redistribute it before publishing a fork. The upstream root project does not
supply this file.

## Icons and signatures

* `app/icon.png` is the SamPwn widget icon.
* `app/author-signature.xml` and `app/signature1.xml` are the public Tizen
  signatures inside the built widget. They contain public certificates, not
  private keys.
* Tizen Studio, the Tizen SDK, and Samsung firmware are not bundled.

`SHA256SUMS` at the repository root covers the complete release tree. Regenerate
it after changing any committed file:

```bash
find . -type f ! -path './.git/*' ! -name SHA256SUMS -print0 \
  | sort -z | xargs -0 sha256sum > SHA256SUMS
```

The daemon was built with the .NET SDK available on the test host. Rebuilding
with another SDK can produce different bytes.
